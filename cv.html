Research Interests

My research lies at the intersection of soft matter physics, molecular simulation, and scientific machine learning. I am interested in developing physics-guided, data-driven surrogate models that accelerate molecular and continuum simulations, enabling access to longer timescales and the exploration of large parameter spaces. I also use hybrid molecular dynamics/Monte Carlo (MD/MC) methods to study charge regulation effects in soft matter. Recently, I developed charge regulation machine learning (CR-ML), a hybrid approach that accelerates the charge-update step of these simulations by more than an order of magnitude.

Keywords: Data-Driven Surrogates, Dynamical Systems, Charge Regulation, Molecular Dynamics, Monte Carlo

Open-Source Projects

Simpok pip install simpok

A Python package for phase-field simulation of phase-ordering kinetics, with all compute kernels written in Mojo. It provides Time-Dependent Ginzburg–Landau (Model A), Cahn–Hilliard–Cook (Model B), and surface-directed spinodal decomposition solvers. Same code runs on CPU and a GPU backend (NVIDIA, AMD, Apple).
